# RIFT — помощник для Path of Exile 1

## Скачать

**[Скачать полный проект RIFT.zip](https://github.com/Qwecxz05/RIFT/raw/refs/heads/main/RIFT.zip)**

Архив содержит весь исходный код, изображения и необходимые данные проекта. Отдельно скачивать Exile-UI не требуется.

## Установка и запуск

1. Установите **AutoHotkey v1.1.36 или новее в ветке v1.1, 64-bit Unicode** с [официального сайта](https://www.autohotkey.com/download/1.1/). AutoHotkey v2 для этой сборки не подходит.
2. Распакуйте архив целиком в отдельную папку. Не запускайте скрипт из ZIP.
3. Запустите Path of Exile 1 в оконном или безрамочном режиме, затем откройте `RIFT/RIFT.ahk` через AutoHotkey v1.1 x64.
4. При первом запуске укажите свои пути к настройкам игры и `Client.txt`, если программа их запросит.

## Управление

- `Ctrl + Alt + R` — настройки RIFT.
- `Ctrl + Alt + N` — открыть/скрыть заметки.
- При включённом Act-Tracker удержание `Tab` около 0,2 секунды переключает режим стрелок: включить / выключить. Отпускание клавиши не выключает режим.
- Стрелки появляются только при распознавании маркера игрока на развёрнутой карте и наличии направлений в текущем шаге гайда. Это общие направления, не навигация по коридорам. Масштаб, цвета интерфейса и боевые эффекты могут мешать распознаванию.

Личные заметки, настройки, PoB-билды, история забегов и пути автора в архив не включены. Настройки создаются локально для каждого пользователя. Схемы локаций при необходимости загружаются через встроенный установщик.

Это экспериментальная сборка: проверены код и отдельные сценарии, но не все игровые ситуации. Подробности — в документации внутри архива.
